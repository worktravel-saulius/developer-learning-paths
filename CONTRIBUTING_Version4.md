# Contributing to Developer Learning Paths

Thanks for helping improve the learning experience for developers.

## Goals

We want to create clear, actionable, and practical learning content that supports real-world engineering progress.

## Accepted Contributions

- tutorials
- learning modules
- process improvements
- project-based guidance
- documentation updates
- workflow templates

## Contribution Guidelines

- keep material practical and clear
- focus on real-world learning
- keep content beginner-friendly but technically solid
- prefer examples and step-by-step structure
- ensure understanding is measurable

## Review Standard

Contributions should:
- be readable
- be relevant
- include examples where useful
- fit the learning flow
- improve onboarding or advancement

- skill building

- mentorship support
