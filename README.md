# Developer Learning Paths

This repository contains practical, contributor-ready learning tracks for developer growth, AI tooling adoption and software-engineering readiness.

## Focus areas

- AI engineering foundations
- full-stack development
- GitHub and DevOps workflows
- cloud-based engineering
- code review and governance
- technical writing and documentation
- project-based contribution

## Learning approach

The paths support a progression from **learner → contributor → collaborator → project builder** through practical outputs such as:

- tutorials and documentation improvements;
- implementation modules and debugging notes;
- code-review artefacts;
- project case studies; and
- portfolio-ready contributions.

## Contribution and recognition

Learning evidence can be linked to real project work through focused pull requests, peer review and public accountability.

> Completing a learning path, opening or merging a pull request, or sponsoring the programme does **not** automatically grant Academy credits, a Copilot seat, payment, employment, project access or a cohort place. Any future recognition is subject to eligibility, capacity, verified identity, policy and human review.

## How to contribute

1. Review [`CONTRIBUTING_Version4.md`](./CONTRIBUTING_Version4.md).
2. Choose a small, clearly scoped improvement to a learning resource, template or guide.
3. Include source references or reproducible examples where applicable.
4. State the learning or operational benefit in the pull request.

For review-first contribution standards, see [`contributor-verification-system`](https://github.com/worktravel-saulius/contributor-verification-system). For programme context, see [`worktravel-academy-core`](https://github.com/worktravel-saulius/worktravel-academy-core).
